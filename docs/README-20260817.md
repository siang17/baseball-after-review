## Phase 2（已完成，端對端瀏覽器驗證通過）

目標：把模擬引擎升級到能產生真實逐球資料，`/replay` 從靜態示範改成「選真實比賽 → 選/編輯打線（含遺珠代入）→ 產生完整逐球復盤」，復盤畫面含好球帶九宮格、壘包示意圖、打擊熱區、打擊軌跡圖（安打紅字 "hit"／全壘打黃字 "homerun"）、對戰投手數據、代打代跑決策點、遺珠代入後的守備/打擊評估比較。完整設計見 `~/.claude/plans/functional-honking-honey.md`。

### 已完成並實測驗證

- **`src/lib/simulation/gameSim.ts`（改）**：壘包從 `[0,0,0]` 數字旗標改成 `[string|null,string|null,string|null]` 真實球員 id；`simulateGame()`/`simulateHalfInning()` 新增可選的 `onPlateAppearance` 逐打席事件回呼（`matchupSimulator.ts` 不傳這個參數，既有聚合模擬行為完全不受影響）。
- **`src/lib/simulation/pitchSynthesizer.ts`（新）**：`synthesizePitches()`，在打席結果（K/BB/HR/…）已經決定之後，合成 1–8 球的逐球細節（球種/球速/好壞球判決/落點/`battedBall`），邏輯保證收在跟結果一致的最後一球（三振收好球、保送收壞球、安打收 in-play）。
- **`src/lib/simulation/syntheticBvp.ts`（新）**：`syntheticBvp(batterId, pitcherId)`，決定性種子生成示範用小樣本對戰數據。
- **`src/lib/simulation/gameReviewGenerator.ts`（新）**：`generateGameReview(homeRoster, awayRoster, game, seed)`，整合 PA 迴圈 + 逐球合成 + `sabermetrics.ts` 既有的勝率/槓桿/RE24 函式，產出完整 `GameReview`（`pitches`/`winProbability`/`crucialPlays`/`decisionPoints`/`pitcherUsage`）。

**驗證方式**：寫了一個暫時的 debug API route，實際呼叫 `generateGameReview` 跑 2026 JPN vs VEN：
- 同一顆 seed 兩次呼叫結果逐位元組相同（決定性可重現）。
- 20 顆不同 seed 掃過一輪，`badPitchCount` 全部是 0（無 NaN / 異常球速 / 異常座標）。
- 勢均力敵的比賽（比分差距小）會產生 2 個代打/換投決策點，懸殊比分的比賽是 0 個——符合「高槓桿情境才觸發」的設計預期。
- 驗證完後 debug route 已刪除，不會留在正式程式碼裡。
